# v10 관인 겹침 배치 개선

## 변경 사항

- 공문서 발신명의 `사단법인 대한불교밀교종` 끝 글자 `종` 위에 관인이 자연스럽게 겹쳐 보이도록 구조와 CSS를 변경했습니다.
- 문서작성 미리보기와 문서 상세보기에서 동일한 발신명의 구조를 사용하도록 통일했습니다.
- 인쇄 및 PDF 파일 저장용 새 창의 전용 CSS에도 같은 관인 위치를 반영했습니다.
- 투명 여백이 큰 PNG 관인을 등록해도 실제 인영 영역을 자동으로 찾아 화면 표시용 이미지를 잘라내도록 개선했습니다.
- 신규 관인 업로드 시 투명 여백을 제거한 이미지가 저장되도록 보완했습니다.
- 기존에 저장된 관인도 다시 업로드하지 않아도 설정 조회 시 화면 표시용으로 자동 보정됩니다.

## 데이터베이스 영향

- 데이터베이스 스키마 변경은 없습니다.
- 기존 문서, 계정, 결재선, 서식 및 저장된 관인 원본 데이터는 유지됩니다.
