## 전체 Astro 빌드
검증 컨테이너의 내부 npm 저장소에서 `zwitch@2.0.4` 파일을 찾지 못해 `npm ci`가 404로 중단되었습니다. 소스 문법이나 형식검사 실패는 아니며, 실제 배포 환경에서는 의존성 설치 후 `npm.cmd run build`를 반드시 실행해야 합니다.
