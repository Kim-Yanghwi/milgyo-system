# V61 수계증서 입력·미리보기 보완

적용일: 2026-08-02

## 변경 사항

### 생년월일 입력
- 입력 중에는 값을 강제로 재조합하지 않도록 변경했습니다.
- 월·일 등 일부 구간을 선택하여 삭제해도 `00`이 자동 삽입되지 않습니다.
- 숫자 8자리 입력은 기존처럼 `YYYY-MM-DD` 형식으로 자동 변환됩니다.
- 포커스를 벗어나거나 미리보기·발급을 실행할 때 날짜 형식과 실제 존재하는 날짜 여부를 검증합니다.
- 달력 아이콘을 실제 버튼으로 변경하고 `HTMLInputElement.showPicker()`를 호출하도록 보완했습니다.
- 달력에서 선택한 날짜는 텍스트 입력란과 즉시 동기화됩니다.

### 수계증서 글자 굵기
- `受 戒`, `戒命`, `五戒`를 강제 굵게 렌더링하도록 보완했습니다.
- `姓名`, `生年月日`, `法名`과 각 입력값을 굵게 표시하도록 보완했습니다.
- 오계 1~5의 붉은 한자·한글 명칭을 모두 굵게 표시하도록 보완했습니다.
- `大韓佛敎 密敎宗`, `香天寺 睡翁 眞妙 合掌`을 굵게 표시하도록 보완했습니다.
- 굵은 글꼴 파일이 없는 환경에서도 차이가 보이도록 합성 굵기와 미세 외곽선을 함께 적용했습니다.

### 우측 상단 불상
- 크기를 206×202px에서 170×170px로 축소했습니다.
- 위치를 위쪽으로 이동하여 생년월일의 `일생` 문구와 겹치지 않도록 조정했습니다.
