# V60 증명서 메뉴·수계증서 입력 및 서식 개선

## 1. 증명서 메뉴 통합
- 좌측 메뉴의 `임·직원 증명서`를 `증명서 발급·대장`으로 변경했습니다.
- 하위 메뉴에 `재직증명서 발급·대장`과 `수계증서 발급·대장`을 항상 함께 표시합니다.
- 메인 화면과 증명서 전용 레이아웃에 동일한 메뉴 구조를 적용했습니다.

## 2. 생년월일 직접 입력 개선
- 생년월일을 달력 이동 없이 키보드로 직접 입력할 수 있습니다.
- `19570119`, `1957-1-19`, `1957.1.19` 입력을 `1957-01-19`로 자동 정규화합니다.
- 직접 입력한 날짜를 달력 선택값과 동기화하여 달력 버튼을 열면 해당 날짜가 선택된 상태로 표시됩니다.
- 존재하지 않는 날짜와 미래 날짜는 발급 전에 차단합니다.

## 3. 테스트자료 초기화 범위 확대
- 초기화 미리보기에 `수계증서` 건수를 별도로 표시합니다.
- 실행 시 `ordination_certificates` 발급대장도 삭제 대상에 포함합니다.
- 삭제 후 자동검증과 완료 안내 문구에도 수계증서를 반영했습니다.

## 4. 수계증서 출력 서식 개선
- 상단 `受 戒`, `戒命`, `五戒`를 굵게 표시합니다.
- 우측 불상 그림을 확대하고 우측·하단 방향으로 재배치했습니다.
- 계명 본문을 요청한 네 줄로 고정하고 네 줄에 동일한 가로 축소율을 적용해 글자 크기와 간격을 균일하게 유지합니다.
- 오계 1~5의 번호·계명·본문을 공통 3열 그리드로 배치하여 각 문장의 첫 단어가 같은 세로선에서 시작합니다.
- 은사·계사·증명, 불기 날짜, 발행기관, 사찰·발행자·맺음말을 굵게 표시합니다.
- 불기 날짜를 개별 숫자·단위의 플렉스 배치로 변경해 `2570` 숫자 겹침을 방지합니다.

## 5. 좌측 상단 사찰 도장 선택
- 발급 전에 `향천사 도장 표시` 체크박스로 좌측 상단 도장 포함 여부를 선택할 수 있습니다.
- 표시 여부와 도장 자산 식별자를 D1 컬럼과 발급 스냅샷에 함께 저장합니다.
- 과거 발급본 상세조회와 재출력 시 발급 당시 선택값을 그대로 사용합니다.
- 향후 사찰별 도장을 추가할 수 있도록 `top_seal_key`와 자산 매핑 구조를 분리했습니다.
