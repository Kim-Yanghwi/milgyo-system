# 2026-07-25 안정화 수정 및 점검 결과

## 1. 사용자 요청 반영

- 로그인 화면의 `대한불교밀교종 종단관리시스템` 제목이 한 줄로 표시되도록 카드 폭, 글자 크기, 자간 및 줄바꿈 속성을 조정했습니다.
- 좌측 계정정보 카드에서 `담당부서` 항목명이 줄바꿈되지 않도록 항목명 열 너비를 확대하고 줄바꿈을 금지했습니다.
- 계정 생성 API가 구버전 운영 DB의 `system_users.id` 형식(TEXT 또는 INTEGER)을 자동 판별해 두 형식을 모두 처리하도록 보완했습니다.
- 스키마 버전 값은 최신이지만 실제 컬럼이 누락된 비정상 상태도 검사하고 자동 복구하도록 개선했습니다.
- 계정 저장 중 중복 클릭을 차단하고 성공·오류 상태를 화면에서 구분해 표시하도록 개선했습니다.

## 2. 계정 및 권한 관련 추가 점검

- 아이디 대소문자를 구분하지 않고 중복을 차단합니다.
- 현재 로그인한 본인 계정은 비활성화할 수 없도록 보호합니다.
- 마지막 활성 관리자 계정을 일반 계정으로 변경하거나 비활성화할 수 없도록 보호합니다.
- 계정 수정 시 새 비밀번호가 8자 미만이면 저장되지 않도록 검증합니다.
- 기존 INTEGER형 사용자 ID도 로그인, 문서 결재선 지정, 계정 목록·수정에서 정상 처리되도록 문자열 변환을 보완했습니다.

## 3. 문서·결재·대장 관련 회귀 점검

- 복수 검토자·복수 협조자·최종 결재/전결 결재선 생성과 단계별 처리 흐름을 확인했습니다.
- 현재 단계에 맞지 않는 검토·협조·결재 동작을 서버에서 거부하도록 검증을 강화했습니다.
- 문서 생성, 목록, 상세, 첨부파일, 발송 처리, 임시문서 삭제 흐름을 점검했습니다.
- 접수·발송 등록 및 수정 시 실제 존재하지 않는 날짜가 저장되지 않도록 검증했습니다.
- 문서번호 순번 정보가 실제 데이터보다 뒤처진 경우 자동 복구되도록 점검했습니다.

## 4. 설정 및 입력값 점검

- 허용 용량을 초과한 로고 이미지는 문자열 처리 전에 차단하여 정확한 안내가 표시되도록 수정했습니다.
- 사용자명 공백, 짧은 비밀번호, 잘못된 날짜, 중복 아이디 등 주요 입력 오류를 점검했습니다.
- API 오류는 서버 로그에 원인을 남기되, 사용자 화면에는 내부 구조를 노출하지 않는 안내 문구를 표시합니다.

## 6. 확인 제한사항

현재 작업 환경의 npm 패키지 저장소가 일시적으로 HTTP 503 오류를 반환하여 `astro build` 전체 빌드는 실행하지 못했습니다. 대신 TypeScript 정적 검사, 브라우저 인라인 JavaScript 문법 검사, SQLite 기반 API 통합·회귀 검사를 수행했습니다. 실제 배포 전에는 정상적인 npm 접속 환경에서 `npm install`과 `npm run build`를 한 번 실행하는 것이 안전합니다.
