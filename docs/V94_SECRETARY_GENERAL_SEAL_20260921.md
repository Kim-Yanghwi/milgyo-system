# V94 사무총장 발신명의 전용 직인 표시

## 반영 목적
전자문서 작성에서 `발신명의 표시방식 = 담당부서장 직책만 표시`이고 담당부서가 정확히 `사무처`인 경우, 표시되는 `사무총장` 발신명의의 마지막 글자 `장` 위치에 사무총장 전용 직인을 겹쳐 표시합니다.

## 변경 범위
- `src/pages/index.astro`
  - 작성 미리보기 조건부 직인 표시
  - 문서 상세 미리보기 조건부 직인 표시
  - 상세 문서 인쇄 CSS에 동일 위치 반영
- `public/secretary_general.png`
  - 투명 배경 사무총장 전용 직인 이미지
- `tests/v94-secretary-general-seal.test.ts`
  - 기존 종단 직인 코드 비변경 및 조건부 표시 회귀 검사
- `scripts/check-v94-secretary-general-seal.mjs`
  - 의존성 설치 없이 핵심 파일/조건을 점검하는 간이 검사

## 표시 조건
아래 조건이 모두 참일 때만 표시합니다.
1. 발신명의 표시방식: `담당부서장 직책만 표시`
2. 담당부서: `사무처` (하위부서가 없는 정확한 사무처)
3. 계산된 담당부서장 직책: `사무총장`

`사무처 - 재정국` 등 하위 부서, 기본 종단 발신명, 직함·성명 추가 방식에서는 사무총장 직인을 표시하지 않습니다.

## 기존 직인 코드 보호
기존 종단 직인은 계속 `data-stamp` 및 `organization-seal-official.png`/관인 설정값을 사용합니다. 사무총장 직인은 `data-stamp`에 포함하지 않고 별도 이미지 요소로 렌더링하므로 기존 관인 등록·교체·적용 로직을 변경하지 않습니다.

## DB / Cloudflare 설정
- D1 migration 없음
- R2 변경 없음
- wrangler 설정 변경 없음

## 배포 후 확인
1. 문서작성 → `담당부서: 사무처`
2. 발신명의 표시방식 → `담당부서장 직책만 표시`
3. 미리보기에서 `사무총장`의 `장` 글자에 전용 직인이 겹치는지 확인
4. 작성 문서를 열어 상세 미리보기와 인쇄에서도 같은 위치인지 확인
5. 기본 발신명의를 선택하면 기존 종단 직인만 표시되는지 확인
