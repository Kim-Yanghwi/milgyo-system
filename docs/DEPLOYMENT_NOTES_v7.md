# v7 배포 메모

1. 기존 Cloudflare Pages 프로젝트의 소스를 v7 전체 소스로 교체합니다.
2. 기존 D1 `DB`, R2 `FILES`, 환경변수 `ADMIN_TOKEN` 바인딩은 그대로 유지합니다.
3. 정상적인 npm 환경에서 `npm install` 후 `npm run build`를 실행합니다.
4. 배포 후 관리자 계정으로 로그인해 계정 1개를 시험 생성합니다.
5. 대외문서를 작성·승인한 뒤 발송대기함과 접수·발송 등록 선택목록에 나타나는지 확인합니다.

D1 테이블과 컬럼은 첫 API 요청 때 자동 보완되므로 별도 SQL 실행은 원칙적으로 필요하지 않습니다. 기존 계정, 문서, 첨부파일 데이터는 삭제하지 않습니다.
