# 2026-07-25 온나라형 UI·안정성 통합 개선 내역

## 문서함·대장

- 임시저장함, 진행문서함, 결재대기함, 발송대기함, 문서등록대장, 완료문서함, 반려문서함을 동일한 고정 테이블 구조로 통일
- 접수·발송대장도 동일한 전체폭 테이블 구조로 통일
- 조회 결과가 0건이거나 API 응답을 기다리는 동안에도 테이블 머리글과 열 너비가 유지되도록 개선
- 문서번호·구분·등록일·제목·담당부서·기안자·검토자·결재자·상태 열을 고정하고 모든 셀을 가운데 정렬
- 긴 문서 제목과 부서명은 표 내부에서 안전하게 줄바꿈 또는 말줄임 처리

## 로그인·성능·새 탭 동기화

- 새로고침 시 로그인 화면이 잠시 나타나는 현상을 제거하기 위해 HTML 파싱 전에 로그인 상태를 판별하도록 개선
- 기존 sessionStorage 로그인 정보를 localStorage로 자동 이전
- 같은 브라우저의 새 탭에서 로그인 상태가 자동 공유되도록 개선
- 다른 탭에서 로그아웃하면 현재 탭도 즉시 로그인 화면으로 전환
- D1 스키마 버전 표식을 추가하여 매 요청마다 전체 테이블·인덱스·서식 마이그레이션을 반복하던 구조를 제거
- 정상 운영 상태에서는 스키마 버전 1회 조회만 수행하도록 하여 로그인과 목록 조회 지연을 줄임

## 상단 제목·로고·파비콘

- 상단 제목을 `대한불교밀교종 종단관리시스템`으로 변경
- 제목과 로고를 상단 좌측에 밀착 배치
- 기존 금색 `문서` 배지를 제거하고 제공된 로고 이미지로 교체
- 제공된 파비콘을 브라우저 탭 아이콘으로 적용
- 공문서 미리보기에도 기본 로고를 적용하고 관리자 등록 로고가 있으면 해당 로고를 우선 사용

## 계정관리·조직도

- 계정 목록을 성명, 아이디, 직책, 직급, 담당부서, 역할, 결재권, 상태, 관리 열의 고정 테이블로 개선
- 계정이 없어도 고정 테이블 머리글과 빈 상태 화면 유지
- `결재자로 지정 가능`과 `활성 계정` 체크박스를 한 행에 정렬
- 체크박스와 라디오 입력이 입력창 전체폭으로 늘어나는 CSS 충돌을 제거
- 조직도 좌측 부서 탐색 영역을 카드형 현대적 디자인으로 개선
- 조직도 구성원 정보를 성명, 아이디, 직책, 직급, 소속, 구분 테이블로 표시

## 문서작성·공문서 미리보기

- 문서구분(기안/발송)과 결재경로 선택 항목을 한 행에 정렬
- 공문서 미리보기의 기안자·검토자·결재자를 가로 1행 결재란으로 변경
- `결재: 이사장 결재`, `결재: 이사회 의결`, `결재: 전결` 표시를 결재란 바로 아래에 배치
- 발신명의 직함·성명은 선택적으로 표시하도록 기능 추가
- 기본값은 `사단법인 대한불교밀교종`만 표시하며, 선택 시 직함과 성명을 추가
- 문서 상세 미리보기와 인쇄 화면에도 같은 결재란·발신명의 구조 적용

## 배포 안정성

- HTML은 재검증하도록 설정하여 배포 후 이전 인라인 코드가 남는 현상을 줄임
- 로고와 파비콘은 하루 동안 브라우저 캐시하도록 설정
- D1 기존 데이터, R2 바인딩, 관리자 계정, 문서·첨부파일은 변경하거나 삭제하지 않음
