# v27 검토본 변경내역

## 첨부파일 적용 확대

- 기부·후원 증빙 및 기부금영수증 근거자료
- 자산·비품 계약서·사진·취득증빙
- 법인카드 발급·계약서류
- 기존 법인카드 사용내역 영수증 기능 유지
- 사찰·교구 취합자료
- 기본회계 월 결산·마감자료
- 특화 결산 화면의 취합자료별 보고서

## 운영정책

- 허용 확장자 화이트리스트
- 파일당 최대용량, 자료당 최대개수, 자료당 총용량
- 삭제사유 필수 여부
- 보존기한 기록
- 확장자·파일 시그니처 기본검사
- v27 이전 파일은 `legacy_unscanned`로 구분

## 안정화

- 삭제 처리상태 `active → deleting → deleted/error`
- R2 삭제 실패와 보상삭제 실패 재처리 이력
- D1_ONLY/R2_ONLY 관리자 점검목록
- 관리자 수동점검과 정기 Worker 점검
- 감사계정 읽기 전용
- 기존 전자결재·회계 outbox 자동 재처리 포함

## 백업

- D1 2개 전체 SQL export 스크립트
- 소스 릴리스 ZIP과 SHA-256 목록
- 선택적 Rclone 기반 R2 외부 백업
- 운영 백업정책·복구·시험 문서


## 검토본 보완사항

- 법인카드 세액 자동계산: 결제금액의 10%로 통일
- 20,000원 입력 시 세액 2,000원, 세액 제외금액 18,000원 표시
- 사용일자 옆에 `(금)` 형식의 실제 요일 표시
- 서버의 날짜 검증을 실제 존재하는 날짜 기준으로 강화
- 법인카드·수입지출결의 전용 첨부화면도 관리자 운영정책과 서버 권한을 사용하도록 통일
- 관리자 운영화면 초기 권한 로딩 순서 보완
- R2 현재본 백업을 `sync` 방식으로 유지하고 삭제·변경 이력을 별도 보존
