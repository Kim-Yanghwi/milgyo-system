# 규정 기반 문서서식 반영 내역 (v9)

## 검토 범위

- 사용자가 제공한 `규정모음.zip`의 HWPX 23개 파일을 검토했습니다.
- 규정 본문과 별지 서식 180개 표제를 추출해, 전자결재에서 직접 기안·검토·승인하기 적합한 서식을 선별했습니다.
- 대장, 명부, 증서, 위임장, 개인정보 동의서, 외부 신청서처럼 표·서명 원본 형태가 핵심인 서식은 현재의 본문 자동작성 기능보다 별도 업무화면이나 원본 파일 첨부가 적합하므로 이번 기본서식에서 제외했습니다.

## 시스템 동작

- 기존 기본서식 4종과 신규 27종을 합쳐 총 31종을 제공합니다.
- 배포 후 최초 API 호출에서 스키마 버전 `2026-07-25.9`를 확인하고 신규 기본서식을 자동 등록합니다.
- 기존 사용자 서식과 작성 문서는 삭제하거나 덮어쓰지 않습니다.
- 기본서식은 직접 수정되지 않으며, 관리자가 복사본을 만든 뒤 항목과 문구를 조정할 수 있습니다.
- 문서작성 서식 선택창은 업무분야별 그룹으로 표시됩니다.
- 서식관리 화면에는 서식명·규정명·설명을 검색할 수 있는 검색창이 추가됩니다.
