# V59 수계증서 발급·대장

## 신규 기능
- 종단관리시스템 좌측 메뉴에 `수계증서 > 수계증서 발급·대장` 추가
- 수계자 성명, 음력·양력, 생년월일, 법명, 수계일, 은사·계사·증명 및 발행정보 입력
- 수계일 연도를 기준으로 `N:YYYY-01` 형식의 연도별 발급번호 자동 생성
- 발급 완료 후 A4 수계증서 출력창 자동 실행
- 입력내용 미리보기, 과거 발급본 상세조회·재출력·취소
- 기간·상태·성명·법명·발급번호 검색과 CSV 출력
- 목록 생년월일 일부 마스킹, 상세조회 권한 제한

## 서식 재현
- 원본 HWPX에서 배경, 불화, 상단 인영, 하단 직인을 추출해 전용 정적 자산으로 구성
- 원본 글꼴명과 글자 크기를 CSS에 반영
- 동적 문구는 고정 좌표와 자동 폭 조절로 A4 1면 안에 배치
- 원본 글꼴이 없는 PC에서는 대체 글꼴을 적용하고 미리보기 전에 경고 표시

## 데이터·안전성
- D1 `ordination_certificates` 테이블 및 조회 인덱스 추가
- 발급 당시 전체 값을 JSON 스냅샷으로 보존
- 중복 클릭 및 네트워크 재시도로 동일 증서가 중복 발급되지 않도록 요청 식별값 적용
- 발급·취소 작업을 관리 감사기록에 저장
- 발급내역은 삭제하지 않고 취소 상태와 사유를 보존
- 취소된 증서를 재출력할 때 문서 중앙에 `취소본` 표시

## 성능
- 증서 공통 이미지 4종은 Pages 정적 자산과 장기 캐시를 사용
- 목록 조회는 필요한 열만 조회하고 페이지 단위로 제한
- 목록 생년월일은 서버에서 마스킹한 값만 반환
