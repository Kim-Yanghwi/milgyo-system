# 종단관리시스템 안정화 수정 내역 v7

## 1. 계정 생성 안정화

- 운영 D1의 사용자 식별자가 `TEXT`, `INTEGER PRIMARY KEY`, `BIGINT` 등으로 구성된 경우를 모두 판별해 계정을 생성하도록 개선했습니다.
- 구버전 사용자 테이블에 `updated_at`, `is_admin`, `is_active` 등 보조 필수 컬럼이 남아 있어도 자료형에 맞는 초기값을 채우도록 호환 처리를 추가했습니다.
- 이미 존재하는 컬럼마다 `ALTER TABLE` 오류를 발생시키던 마이그레이션을 개선하여 실제 누락 컬럼만 추가합니다.
- 계정 생성 도중 DB 응답만 실패했거나 일시적인 D1 잠금이 발생한 경우, 생성 결과 확인 및 1회 재시도로 복구합니다.
- 동일 아이디의 대소문자 중복을 차단하고 계정 추가 버튼의 중복 클릭을 방지합니다.
- 비밀번호 해시는 PBKDF2 형식을 유지하되 Pages Functions 실행시간을 고려해 반복 횟수를 조정하고, PBKDF2를 제공하지 않는 런타임에서는 기존 호환 해시로 자동 대체합니다.
- 과거 문서의 중복 `client_request_id` 때문에 고유 인덱스 생성과 전체 스키마 보완이 실패하지 않도록 중복값 자동 정리를 추가했습니다.

## 2. 연도별 문서번호

- 문서번호는 한국시간을 기준으로 `밀교종-연도-일련번호` 형식으로 생성됩니다.
- 2026년 12월 31일에서 2027년 1월 1일로 넘어가면 `밀교종-2027-001`부터 새로 시작합니다.
- 같은 연도의 기존 문서번호 최댓값과 순번 테이블을 함께 확인하여 순번 테이블이 초기화되더라도 중복 번호가 생기지 않도록 보정했습니다.
- 미리보기의 임시 문서번호도 현재 한국시간 연도를 자동 표시합니다.

## 3. 공문서 미리보기 머리말

- 로고와 `사단법인 대한불교밀교종`을 같은 줄에 배치하고 로고를 기관명 바로 왼쪽에 붙였습니다.
- 문서번호를 `문서번호 : 밀교종-연도-번호` 형식으로 같은 행의 오른쪽 끝에 배치했습니다.
- 문서 상세화면과 인쇄화면에도 같은 배치를 적용했습니다.

## 4. 발송대기 및 접수·발송대장 연계

- 문서작성에서 `발송(대외)`로 작성해 최종 승인된 문서는 발송대기함과 외부발송 선택목록에 나타납니다.
- 접수·발송 등록에서 `외부발송`을 선택하면 연결 내부문서를 발송대기함의 문서 중에서 선택하도록 변경했습니다.
- 연결 내부문서 선택 항목을 제목 바로 위에 배치했습니다.
- 문서를 선택하면 제목, 수신자, 발송경로, 발송일자, 담당부서, 메모를 자동 입력합니다.
- 등록 시 접수·발송대장에 외부발송 기록을 생성하고 내부문서를 `발송완료`로 변경합니다.
- 같은 내부문서를 중복 발송 등록하지 못하도록 별도 연결 테이블과 고유 제약을 추가했습니다.
- 외부발송 기록을 삭제하면 내부문서를 다시 발송대기 상태로 되돌립니다.
- 문서 상세화면에서 바로 발송완료 처리하는 경우에도 외부발송대장 기록이 함께 생성됩니다.

## 5. 기존 화면 보완 유지

- 로그인 화면 시스템명을 한 줄로 유지하도록 카드 폭과 글자 크기를 조정했습니다.
- 좌측 계정정보 카드의 `담당부서` 항목명이 줄바꿈되지 않도록 항목 폭과 줄바꿈 속성을 보완했습니다.
- 상단 로고와 시스템명을 누르면 홈으로 이동합니다.
- 기존 복수 검토자·협조자, 결재·전결, 첨부파일, 문서함 기능과 구버전 데이터 호환을 유지합니다.
