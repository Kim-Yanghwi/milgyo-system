## 자동 확인 결과

1. 인라인 JavaScript 문법 검사
   - `node --check` 통과

2. 외곽선·그림자 제거 확인
   - V61에서 사용하던 소수점 단위의 비영(非零) `-webkit-text-stroke` 제거 확인
   - V61에서 사용하던 좌우 중첩 `text-shadow` 제거 확인
   - 굵은 글씨 선택자에 `text-shadow: none`과 `-webkit-text-stroke: 0` 적용 확인

3. 굵기·색상 유지 확인
   - 공통 굵은 글씨 클래스에 `font-weight: 900` 및 `font-synthesis: weight` 유지 확인
   - 붉은 오계 명칭의 채움색 `#f00` 유지 확인
   - 검은색 제목·인적사항·발행기관·사찰 문구의 채움색 `#000` 유지 확인

4. 변경 범위 확인
   - 수계증서 위치·크기·문구·발급 로직 변경 없음
   - 데이터베이스 마이그레이션 없음
