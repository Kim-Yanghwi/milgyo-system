# 변경 내역 v8 (2026-07-25)

- 공문서 기관명과 문서번호가 겹치지 않도록 문서번호를 별도 다음 행의 오른쪽에 배치
- 기안자와 최종 결재·전결자가 같고 중간 검토·협조자가 없는 경우 안내창을 표시한 뒤 상신 즉시 승인
- 즉시 승인 문서에 상신·승인 이력, 완료일시, 완료된 결재선을 함께 기록
- 접수·발송 등록의 연결 내부문서 제목·선택박스·안내문 사이 간격 조정
- 문서 목록은 현재 페이지 문서만 조회하고 결재선 인덱스를 이용하도록 쿼리 보완
- 문서 목록의 건수와 페이지 데이터, 접수·발송대장 건수와 페이지 데이터를 각각 D1 batch 한 번으로 조회
- 홈 수량 및 최근 문서 목록도 D1 batch 한 번으로 통합하여 원격 DB 왕복 횟수 축소
- 날짜 검색에서 인덱스를 막는 `substr()` 제거 및 상태·연도·정렬용 복합 인덱스 추가
- 문서 목록 조회 시 대시보드 중복 호출을 15초 캐시·백그라운드 갱신으로 완화
- 화면 전환 중 먼저 보낸 느린 응답이 최신 목록을 덮어쓰지 않도록 요청 순번 검사 추가
- 감사 역할 추가: 계정관리 권한 없이 임시저장을 포함한 모든 전자문서 및 첨부파일 열람 가능
