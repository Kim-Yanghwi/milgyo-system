# v8 배포 메모

1. 기존 Cloudflare Pages 프로젝트의 소스를 v8 전체 소스로 교체합니다.
2. 기존 D1 `DB`, R2 `FILES`, 환경변수 `ADMIN_TOKEN` 바인딩은 변경하지 않습니다.
3. 정상적인 npm 환경에서 `npm install` 후 `npm run build`를 실행합니다.
4. 기존 소스와 D1 데이터베이스를 먼저 백업한 뒤 배포합니다.
5. 배포 후 다음 항목을 확인합니다.
   - 기안자와 결재자가 같은 시험문서가 안내창 후 즉시 승인되는지
   - 기관명 아래 별도 행 오른쪽에 문서번호가 표시되는지
   - 접수·발송 등록의 연결 내부문서 선택영역 간격이 자연스러운지
   - 문서등록대장 및 접수·발송대장 조회속도와 검색·페이지 이동이 정상인지
   - 감사 역할 계정으로 모든 문서와 첨부파일을 열람할 수 있는지

D1 테이블·컬럼·인덱스는 배포 후 첫 API 요청에서 자동 보완됩니다. 별도의 초기화 SQL을 실행하지 않으며 기존 계정, 문서, 결재이력, 첨부파일 데이터는 삭제하지 않습니다.
