# V59 수계증서 기능시험 체크리스트

## A. 메뉴·권한
- [ ] 좌측 메뉴에 `수계증서 발급·대장` 표시
- [ ] 관리자 발급·상세·출력·취소 가능
- [ ] 감사 사용자 목록·상세·출력 가능, 발급·취소 불가
- [ ] 일반 사용자 API 및 화면 접근 차단
- [ ] 비로그인 직접 URL 접근 시 로그인 화면 이동

## B. 입력·검증
- [ ] 성명, 생년월일 기준, 생년월일, 법명, 수계일 필수
- [ ] 잘못된 날짜 서버에서 차단
- [ ] 수계일 입력 시 불기 자동 계산
- [ ] 음력·양력에 따라 증서의 `陰`·`陽` 표시
- [ ] 성명 글자 사이 자동 간격
- [ ] 기본 은사·계사·증명·기관·사찰·발행자 값 표시

## C. 발급번호·중복 방지
- [ ] 2027년 첫 발급 `N:2027-01`
- [ ] 2027년 다음 발급 `N:2027-02`
- [ ] 2028년 첫 발급 `N:2028-01`
- [ ] 발급 버튼 연속 클릭 시 1건만 저장
- [ ] 네트워크 재시도 시 같은 요청 식별값으로 기존 발급본 반환

## D. 증서 미리보기·인쇄
- [ ] A4 세로 1면
- [ ] 배경, 불화, 상단 인영, 하단 직인 표시
- [ ] 제목·성명·생년월일·법명 위치 확인
- [ ] 계명과 오계 문구 줄바꿈 확인
- [ ] 은사·계사·증명·불기·기관·사찰 위치 확인
- [ ] 발급 완료 후 인쇄창 자동 실행
- [ ] 미리보기 인쇄와 대장 재출력 동일
- [ ] 원본 글꼴 미설치 시 경고 표시

## E. 발급대장
- [ ] 목록 생년월일 일자 마스킹
- [ ] 발급번호·성명·법명 검색
- [ ] 수계일 기간 및 상태 필터
- [ ] 페이지 크기 및 페이지 이동
- [ ] 상세 화면 표 정렬
- [ ] CSV UTF-8 BOM 포함 및 한글 정상 표시
- [ ] 취소 사유 필수, 취소 상태와 사유 보존
- [ ] 취소된 증서 재출력 시 `취소본` 워터마크 표시

## F. 회귀시험
- [ ] 공고·관인·인영 대장 정상
- [ ] 재직증명서 발급·출력 정상
- [ ] 전자문서·접수·발송 정상
- [ ] 회계관리 정상
- [ ] 기존 사이드바 접기·모바일 화면 정상
