# Milgyo OS V93 FINAL R1 — 이사장 조화연 전환 최종 정리

## 목적
V93 FINAL 패키지에서 남아 있던 V91.1 회귀 테스트 1건의 잘못된 속성 순서 의존성을 제거합니다.

## 원인
실제 `src/pages/foreign-applications.astro`의 날짜 입력은 다음처럼 정상입니다.

- `data-ledger-from data-no-weekday data-no-date8`
- `data-ledger-to data-no-weekday data-no-date8`

기존 테스트는 `data-no-weekday data-ledger-from`처럼 HTML 속성의 특정 순서를 요구하여 기능이 정상이어도 실패했습니다.

## 보정
`tests/v91-1-immigration-ui-paper.test.ts`에서 날짜 입력 태그가 필요한 세 속성을 모두 포함하는지만 검사하도록 변경했습니다. 속성 순서는 검사하지 않습니다.

## 영향 범위
- 실행 코드 변경 없음
- D1 변경 없음
- R2 변경 없음
- Wrangler 설정 변경 없음
- V91.1 회귀 테스트만 보정

## 최종 검증
저장소 루트에서:

```powershell
node .\scripts\check-v93-final.mjs
npm.cmd test
npm.cmd run build
```
