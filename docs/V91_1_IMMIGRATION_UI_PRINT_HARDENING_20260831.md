# V91.1 출입국 신청서 UI·출력 보정 (2026-08-31)

## 목적
V91 복구본의 출입국 신청서 화면을 운영 화면에 맞게 정리하고, 미리보기/인쇄물을 제공된 HWPX 서식의 표·실선·A4 페이지 구조에 가깝게 보정한다.

## 변경사항
- 메뉴 및 페이지 명칭을 `출입국 신청서 작성·대장`으로 단축.
- 페이지 설명을 `출입국 관련 신청서(신고서)를 화면에서 작성하고, 작성본 다운로드·인쇄 및 이력을 관리합니다.`로 변경.
- `새로 작성` 버튼을 3종 서식 선택 카드 아래 우측으로 이동.
- 원본 HWPX 3종 다운로드를 작성대장 필터 다음 줄 우측으로 이동.
- 미리보기/다운로드/인쇄/PDF/이력 저장 버튼을 우측 정렬하고 간격을 확대.
- 작성대장 날짜 범위를 요일 보조 UI 없이 한 줄 `시작일 ~ 종료일` 구조로 통일.
- 입력 폼을 섹션 단위 카드로 분리해 1., 2. 등의 구분이 인접 열로 밀리지 않도록 고정.
- 거주/숙소제공확인서: 원본 표 구조, 확인문, 서명/직인, 제출 안내를 A4 1쪽 출력으로 재구성.
- 통합신청서(신고서): 신청/신고 체크 영역, 사진칸, 인적/학교/근무/동의/공용란을 A4 1쪽 표로 재구성.
- 사증발급인정신청서: 원본 1~5쪽 흐름에 맞춰 인적·여권·연락처·가족·학력·직업·방문·도움·초청·유의사항/공용란을 5쪽 A4 출력으로 분리.
- HTML 작성본 다운로드와 인쇄/PDF 저장도 동일한 출력 템플릿을 사용.

## 영향 범위
DB/API 스키마 변경 없음. 기존 V91 `foreign_application_forms` 저장 데이터와 호환된다.
