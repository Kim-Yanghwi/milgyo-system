# v27 회계 첨부파일 통합시험 계획

## A. 메뉴별 첨부시험

각 항목에서 등록 → 목록 → 다운로드 → 삭제 순서로 시험한다.

| 업무 | reference_type | 대표 자료 |
|---|---|---|
| 수입·지출결의 | resolution | 결의서 증빙 |
| 기부·후원 | donation | 입금·약정 증빙 |
| 기부금영수증 | receipt | 발급 근거자료 |
| 자산·비품 | asset | 계약서·사진 |
| 법인카드 | card | 발급·계약 서류 |
| 법인카드 사용내역 | card_transaction | 영수증·매출전표 |
| 사찰·교구 취합 | branch_report | 제출보고서 |
| 기본회계 월 마감 | closing | 월 결산자료 |
| 특화 결산자료 | closing | 통합 결산보고서 |

## B. 운영정책 시험

- 허용 확장자 PDF/JPG/PNG/HWP/HWPX/DOC/DOCX/XLS/XLSX/CSV/TXT 정상 등록
- 실행파일·HTML·JavaScript 등 차단
- 확장자만 바꾼 위장파일 차단
- 파일당 최대용량 초과 차단
- 건당 최대 개수 초과 차단
- 건당 총용량 초과 차단
- 삭제사유 미입력 차단
- 보존기한 및 기본검사 상태 목록 표시

## C. 권한 시험

| 계정 | 조회 | 등록 | 본인 파일 삭제 | 타인 파일 삭제 | 정책·점검 처리 |
|---|---:|---:|---:|---:|---:|
| 회계관리자 | 가능 | 가능 | 가능 | 가능 | 가능 |
| 일반 회계사용자 | 허용 자료만 | 허용 자료만 | 가능 | 불가 | 불가 |
| 감사계정 | 가능 | 불가 | 불가 | 불가 | 조회만 |

## D. 회귀시험

- 수입·지출결의 등록 및 전표 확정
- 확정 전표는 직접삭제 없이 역분개로 취소
- 마감된 기간의 전표 변경·취소 차단
- 법인카드 등록·삭제 및 빈 카드코드 재사용
- 카드 결제금액 20,000원 입력 시 세액 2,000원, 세액 제외금액 18,000원 자동표시
- 면세 선택 시 세액 0원, 직접입력 선택 시 사용자 입력값 반영
- 사용일자 2026-07-31 선택 시 `(금)` 표시
- 기부금영수증 발급 흐름
- 자산·비품 등록
- 사찰·교구 취합 및 특화 결산

## E. 무결성 점검시험

운영자료를 임의로 삭제하여 시험하지 않는다. 별도 시험자료로 다음을 검증한다.

1. 정상자료 상태에서 `D1 기준 점검` 결과가 0건인지 확인
2. 정상자료 상태에서 `D1·R2 전체 점검` 결과가 0건인지 확인
3. 시험용 R2 단독 객체를 만든 경우 `R2_ONLY` 표시 확인 후 관리자 화면에서 삭제
4. 시험용 D1 단독 메타정보를 만든 경우 `D1_ONLY` 표시 확인 후 논리삭제 처리
5. 점검단계에서는 자동삭제되지 않고 관리자 목록에만 표시되는지 확인

## F. 합격 기준

- 주요 메뉴별 업로드·다운로드·삭제가 모두 성공
- 권한 우회 불가
- 정상파일에서 무결성 오류 0건
- 기존 회계 핵심기능 회귀오류 없음
- 정기점검 Worker 로그에 예외 없음
