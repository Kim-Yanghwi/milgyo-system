# v24 회계표 동적 행 정렬 확정

## 원인
회계표의 본문 행은 JavaScript `innerHTML`로 동적으로 생성됩니다. 기존 CSS는 Astro scoped CSS로 변환되어 정적 마크업에는 적용되지만, 동적으로 생성된 `td`에는 Astro scope 속성이 없어 일부 정렬과 실선 규칙이 적용되지 않았습니다.

## 수정
- 동적 표 행에 `cell-center`, `cell-number` 클래스를 명시적으로 부여했습니다.
- 동적 행에도 적용되도록 정렬 및 실선 CSS를 `:global(...)` 선택자로 변경했습니다.
- 합계잔액시산표 본문 1~3열은 가운데 정렬, 4~6열은 오른쪽 정렬로 고정했습니다.
- 월별 마감표 본문 1월~12월, 상태, 관리 버튼을 모두 가운데 정렬했습니다.
- 계정과목표 본문 6개 열을 모두 가운데 정렬했습니다.
- 동적으로 만들어지는 모든 회계표 셀에도 행·열 실선이 표시되도록 보완했습니다.
