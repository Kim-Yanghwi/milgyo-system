# 변경 내역 v9 — 규정 기반 기본서식 확장

## 주요 변경

- `규정모음.zip`의 HWPX 23개와 별지 서식 표제 180개를 분석했습니다.
- 전자결재 기안에 적합한 기본서식 27종을 추가해 총 31종으로 확대했습니다.
- 서식 선택창을 일반·업무, 재무·회계, 후원·기부금, 시설·계약, 안전·보험, 교육·인사, 법회·의례·수행, 문서·인장, 회의, 윤리·징계로 그룹화했습니다.
- 서식관리 화면에 서식명·규정명·설명 검색 기능을 추가했습니다.
- 신규 서식은 규정의 핵심 항목을 구조화해 입력하면 본문이 자동 작성되도록 구성했습니다.
- 스키마 버전을 `2026-07-25.9`로 올려 기존 운영 DB에도 신규 기본서식이 자동 등록되도록 했습니다.

## 호환성

- 기존 문서, 계정, 사용자 서식, 첨부파일에는 변경을 가하지 않습니다.
- 기존 기본서식 4종은 그대로 유지됩니다.
- 기본서식 ID를 고정해 재배포 시 중복 생성되지 않습니다.
