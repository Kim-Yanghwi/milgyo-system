  - 취소 상태 및 취소사유 저장

- ZIP 생성 전 파일·SQL 무결성 검사

## 중복 발급 방지
사용자 연속 클릭을 화면에서 차단하고, 서버에서도 `request_id` 고유값으로 같은 요청을 재사용합니다. 응답이 유실된 뒤 재시도해도 새로운 증서번호를 추가 발급하지 않습니다.

## 전체 Astro 빌드 관련
현재 검증 컨테이너의 내부 npm 저장소에 `zwitch@2.0.4` 패키지가 없어 `npm ci` 단계가 404로 중단됐습니다. 코드 오류로 인한 빌드 실패는 아니며, TypeScript·JavaScript·SQL·API·브라우저 런타임 검사는 별도로 통과했습니다. 실제 프로젝트 환경에서는 배포 전에 `npm.cmd run build` 또는 기존 빌드 명령을 실행해야 합니다.

## 글꼴
원본 HWPX가 참조하는 상용/로컬 글꼴 파일은 배포물에 포함하지 않았습니다. CSS에는 원본 글꼴명과 대체 글꼴 순서를 지정했으며, 한컴오피스 글꼴이 설치된 Windows 인쇄 PC에서 가장 동일하게 출력됩니다.
