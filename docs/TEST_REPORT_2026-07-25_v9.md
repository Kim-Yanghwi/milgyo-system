## 빌드 관련

- `npm install`은 작업환경의 패키지 저장소 응답 지연으로 제한시간 내 완료되지 않았습니다.
- TypeScript 및 브라우저 JavaScript 정적검사는 통과했습니다.
- 배포 환경에서 `npm install` 후 `npm run build`를 실행해 최종 빌드를 확인해야 합니다.
