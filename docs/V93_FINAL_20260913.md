# Milgyo OS V93 FINAL — 이사장 표시/기본값/순서 최종 정리

## 최종 결론
운영 D1 직접 조회 결과, 사용자 원장 자체는 이미 목표 상태였습니다.

- 조화연: 이사장 / 이사장, 활성, 결재권한·회계권한 보유
- 김양휘: 사무총장 / 사무처, 활성
- 김양휘가 이사장으로 남은 전자결재 문서: 0건
- 김양휘가 이사장으로 남은 결재선: 0건
- 김양휘가 이사장으로 남은 재직증명서: 0건
- 회계 조직 대표자에서 김양휘/조화연 직접 참조: 0건
- 기부금영수증 발급자에서 김양휘/조화연 직접 참조: 0건
- 과거 소속증명원의 김양휘 이사장 기록: 0건

따라서 최종본은 운영 D1 데이터를 다시 쓰는 migration을 사용하지 않습니다.

## 코드 변경
1. 사용자 목록에서 조화연과 김양휘를 기존 김양휘 최초 위치에 묶어 배치하고 조화연을 먼저 표시합니다.
2. 재직증명서 사용자/발급명의 후보에서 조화연을 김양휘보다 먼저 표시합니다.
3. 회계 소속증명원 등 이사장 후보에서 조화연을 우선 표시합니다.
4. 재직증명서 신규 스키마/화면 fallback 기본 이사장 이름을 조화연으로 변경합니다.
5. 과거 migration `0005_v61_employment_certificate_signatory.sql`은 역사 이력 보존을 위해 수정하지 않습니다.
6. `0012_v93_chairman_handover.sql`, `0019_v93_chairman_handover.sql`은 최종 버전에서 사용하지 않습니다.
7. V91.1 테스트의 지나치게 엄격한 class 문자열 검사를 현재 동적 class 구조에 맞게 보정합니다.
