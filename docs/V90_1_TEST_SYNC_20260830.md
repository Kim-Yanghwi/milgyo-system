# V90.1 Verify test sync hotfix

## Cause
V90 intentionally cache-busts the shared date helper as `/milgyo-date-input.js?v=90`.
One older regression assertion in `tests/tax-accounting-regression.test.ts` still required `?v=89`, while the newer V89/V90 regression test already required `?v=90`.

## Change
Only the stale test expectation was updated from `v=89` to `v=90`.
Runtime source, UI, DB schema, migrations, Cloudflare bindings, and deployed behavior are unchanged.

## Expected verification
`npm.cmd run verify` should no longer fail on the date helper asset version assertion.
