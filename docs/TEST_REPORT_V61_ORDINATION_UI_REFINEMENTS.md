# V61 수계증서 입력·미리보기 보완 시험 결과

시험일: 2026-08-02

## 자동 확인 결과

1. 인라인 JavaScript 문법 검사
   - `node --check` 통과

2. 생년월일 입력 브라우저 시험
   - `19570119` 입력 시 `1957-01-19` 자동 변환 확인
   - `1957-01-19`에서 월 `01`만 선택하여 삭제 시 `1957--19`로 유지 확인
   - 삭제 중 `00` 자동 삽입 없음 확인
   - 달력 버튼 클릭 이벤트와 네이티브 날짜 선택기 호출 확인
   - 달력에서 선택한 날짜가 텍스트 입력란에 반영되는지 확인

3. 수계증서 미리보기 브라우저 시험
   - 제목, 인적사항, 계명·오계, 붉은 오계 명칭, 발행기관·사찰 문구의 계산된 글꼴 굵기 `900` 확인
   - 대상 문구에 미세 외곽선 적용 확인
   - 우측 상단 불상 하단과 생년월일 문구 상단 사이에 간격이 존재하는지 확인

4. 전체 빌드
   - 실행 환경의 내부 npm 저장소에서 `zwitch@2.0.4` 파일이 404로 응답하여 `npm ci` 및 전체 Astro 빌드는 수행하지 못했습니다.
   - 소스 자체의 인라인 JavaScript 문법과 브라우저 동작 시험은 별도로 통과했습니다.

## 배포 시 확인 사항

- 별도 데이터베이스 마이그레이션은 없습니다.
- 기존 V60 마이그레이션이 적용된 소스에 V61 파일을 배포하면 됩니다.
- 배포 환경에서 `npm ci` 또는 의존성 설치 후 `npm run build`를 한 번 실행해 주세요.
- 실제 Windows 운영 단말에서 미리보기와 인쇄 결과의 굵기 및 불상 위치를 최종 확인해 주세요.
