# v14 발신명의 및 결재순서 개선

## 발신명의 표시
- `직함·성명 표시`를 활성화하면 기관명과 같은 줄에 붙지 않고 다음 줄에 표시되도록 변경했습니다.
- 직함·성명 줄의 오른쪽 끝을 기관명 마지막 글자 `종`의 오른쪽 끝과 맞췄습니다.
- 관인은 기관명에만 겹치며 직함·성명 줄과 겹치지 않도록 줄 간격을 확보했습니다.
- 하단 `사단법인 대한불교밀교종 · milgyo.org` 문구를 더 아래로 이동했습니다.
- 미리보기, 상세보기, 인쇄 및 PDF 저장 화면에 동일하게 적용했습니다.

## 결재선 순서
- 문서작성 화면의 지정 순서를 `협조자 → 검토자 → 최종 결재·전결자`로 변경했습니다.
- 공문서 미리보기의 결재선도 `기안 → 협조 → 검토 → 결재·전결` 순서로 변경했습니다.
- 서버의 실제 처리 순서도 협조 완료 후 검토, 이후 최종 결재·전결이 진행되도록 변경했습니다.
- 문서 종류 안내 문구를 `협조자 또는 검토자(선택사항 · 복수 가능) → 최종 처리자` 방식으로 수정했습니다.

## 호환성
- 기존 완료문서와 기존 결재이력은 변경하지 않습니다.
- 수정본 적용 후 새로 상신하거나 임시저장 문서를 다시 상신하는 경우 새 처리 순서가 적용됩니다.
